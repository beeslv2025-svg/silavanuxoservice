# เว็บไซต์ SILAVAN UXO SERVICES — คู่มือใช้งาน

อัปเดตล่าสุด: 7 สิงหาคม 2026

เว็บนี้เป็น **static site** ล้วน (ไม่มี PHP, ไม่มีฐานข้อมูล) ออกแบบมาให้ลงบน **Cloudflare Pages** ได้ตรงๆ

## 1. ไฟล์ในโฟลเดอร์นี้

| ไฟล์ / โฟลเดอร์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บทั้งหมด — HTML, CSS, JS อยู่ในไฟล์เดียว |
| `privacy.html` | นโยบายความเป็นส่วนตัว (ลูกค้าองค์กร/NGO มักขอดู) |
| `404.html` | หน้าที่แสดงเมื่อเปิด URL ที่ไม่มีอยู่ |
| `images/` | รูปทั้งหมด 47 รูป — โลโก้, ทีมงาน, UXO ที่พบจริง, เครื่องจักร |
| `videos/` | คลิป 6 คลิป + รูปปก เก็บไว้ในเว็บเอง ไม่พึ่ง YouTube |
| `_headers` | ตั้งค่า security header + cache ให้ Cloudflare (อ่านอัตโนมัติ) |
| `robots.txt`, `sitemap.xml` | สำหรับ Google |
| `.claude/` | เครื่องมือทดสอบเว็บในเครื่อง (ไม่ต้องอัปโหลดก็ได้) |

## 2. วิธีขึ้นเว็บบน Cloudflare Pages

1. เข้า https://dash.cloudflare.com → เมนู **Workers & Pages**
2. เลือกโปรเจกต์ `silavan` (หรือ **Create → Pages → Upload assets** ถ้ายังไม่มี)
3. กด **Create new deployment**
4. **ลากทั้งโฟลเดอร์ `silavan-website` เข้าไปวาง** (ไม่ต้อง zip)
5. รอสัก 1–2 นาที → เสร็จ

> ขนาดรวมประมาณ 42 MB ถ้าเน็ตช้าอาจใช้เวลาอัปโหลดสักพัก
> Cloudflare Pages จำกัดไฟล์ละไม่เกิน **25 MB** — คลิปที่ย่อไว้แล้วใหญ่สุด 10.4 MB ผ่านสบาย

## 4. วิธีแก้ของที่ต้องอัปเดตบ่อย

### ตัวเลขสถิติ
ค้นคำว่า `===== STATS` ใน `index.html` — ตัวเลขปัจจุบันมาจาก **SLV UXO Annual Report 2025 ที่ส่งให้ NRA**:

| ตัวเลข | ที่มา |
|---|---|
| 146 พนักงาน | รายงานประจำปี 2025 (สำนักงาน 8 + ปฏิบัติการ 146) |
| 571 เฮกตาร์ (ปี 2025) | 414.49 เกษตร + 156.99 พัฒนา |
| 60+ ใบรับรองการเก็บกู้ | นับจากไฟล์ UXO Clearance Completion Certificate |
| 80+ โครงการและลูกค้า | นับจากโฟลเดอร์โครงการใน `D:\GIS_SLV_ Report` |

แก้ทั้ง `data-n="146"` และตัวเลขใน `<b>` ให้ตรงกันด้วย

### แก้หรือเพิ่มข้อความ (เว็บรองรับ 5 ภาษา)
เว็บมี **ลาว / อังกฤษ / จีน / ไทย / เวียดนาม** สลับด้วยปุ่มมุมขวาบน
กลไกคือ CSS ซ่อนทุกภาษาที่ไม่ได้เลือก — ค้น `language switching` ใน `<style>`

ข้อความทุกชิ้นจึงต้องมี **ครบทั้ง 5 ชุด** วางติดกัน เรียงลำดับเดิมเสมอ:

```html
<h3 lang="lo">ສົ່ງມອບ ແລະ ຢັ້ງຢືນ</h3><h3 lang="en">Handover &amp; Certify</h3><h3 lang="zh">移交与认证</h3><h3 lang="th">ส่งมอบและรับรอง</h3><h3 lang="vi">Bàn giao &amp; chứng nhận</h3>
```

> ⚠️ ถ้าใส่ไม่ครบ ภาษาที่ขาดจะกลายเป็น **ช่องว่าง** ไม่ใช่ fallback เป็นอังกฤษ
>
> ⚠️ ห้ามใส่ `lang="..."` บนปุ่มสลับภาษาเอง — CSS จะซ่อนปุ่มนั้นทิ้ง

ข้อความที่ JS เขียนเอง (ไม่ใช่ `<span lang>`) อยู่รวมกันที่ตัวแปร `SLV_T`
ท้าย `index.html` เช่น ข้อความเตือนของฟอร์ม, ตัวเลือกใน `<select>`, `<title>`
ส่วนคำบรรยายสไลด์หน้าแรกใช้ attribute `data-cap-lo` / `-en` / `-zh` / `-th` / `-vi`

หน้า `privacy.html` มีปุ่มสลับภาษาชุดเดียวกัน (จำค่าร่วมกันผ่าน `slv-lang`)
ส่วน `404.html` ไม่มีปุ่ม — แสดงทั้ง 5 ภาษาเรียงลงมาเลย

### เพิ่มคลิปวิดีโอ
1. วางไฟล์ `.mp4` ใน `videos/` (ชื่อภาษาอังกฤษ ห้ามเว้นวรรค)
2. ทำรูปปก `.jpg` ชื่อเดียวกันวางคู่กัน
3. ค้น `var slvVideos` ท้าย `index.html` แล้วเพิ่มบล็อกใหม่ (ช่อง `file` ไม่ต้องใส่นามสกุล)
   — ต้องใส่ชื่อคลิปครบ 5 ช่อง: `titleLo` / `titleEn` / `titleZh` / `titleTh` / `titleVi`

ถ้าคลิปใหญ่เกิน 25 MB ให้ย่อก่อนด้วยคำสั่งนี้:
```bash
ffmpeg -i คลิปต้นฉบับ.mp4 -vf "scale='min(1280,iw)':-2" -c:v libx264 -crf 27 -preset slow -movflags +faststart -c:a aac -b:a 96k videos/ชื่อใหม่.mp4
```

### สีของโหมดมืด
ทั้งเว็บใช้ตัวแปร CSS ชุดเดียว แก้สีที่เดียวได้ทั้งหน้า — ค้น `[data-theme="dark"]` ใน `index.html`

| ตัวแปร | หน้าที่ | สว่าง | มืด |
|---|---|---|---|
| `--bg` / `--bg-soft` | พื้นหน้า | `#ffffff` / `#f5f8fb` | `#0c1520` / `#101c28` |
| `--card` | พื้นการ์ด | `#ffffff` | `#152331` |
| `--head` | สีหัวข้อ | `#084a7c` | `#8fcbf5` |
| `--ink` / `--muted` | ตัวหนังสือ | `#1e2a35` / `#5b6b7a` | `#e4ecf4` / `#93a8bd` |
| `--line` | เส้นขอบ | `#e3e9ef` | `#233240` |

> ⚠️ `--head` (สีหัวข้อ) กับ `--blue-dark` (พื้นแถบบน/footer) เป็นคนละตัวโดยตั้งใจ
> ห้ามเอามารวมกัน ไม่งั้นพอสลับโหมดจะมีฝั่งหนึ่งอ่านไม่ออก
>
> ⚠️ อย่าใส่ `transition` กับ property ที่ค่ามาจากตัวแปร (เช่น `transition:background`)
> เบราว์เซอร์จะค้างสีเดิมตอนสลับโหมด — เคยเจอมาแล้วกับ `header`

### เพิ่มรูปในแกลเลอรี
ค้น `mq-track` ใน `index.html` — แต่ละแถวคือแถบรูปเลื่อนหนึ่งแถว
รูปในแถวต้องใส่ **สองรอบ** (รอบสองใส่ `aria-hidden="true" tabindex="-1"` และ `alt=""`) เพื่อให้เลื่อนต่อเนื่องไม่มีรอยต่อ

## 6. เมื่อได้โดเมนของตัวเองแล้ว

ตอนนี้ **ยังไม่ได้ตั้งโดเมน** — URL เต็มถูกถอดออกจากไฟล์หมดแล้ว เว็บใช้งานได้ปกติทุกอย่าง
แต่ยังขาด canonical / og:url / sitemap จนกว่าจะใส่โดเมน

ทุกจุดที่ต้องแก้มี **คอมเมนต์บอกไว้ในไฟล์แล้ว** ค้นคำว่า `example.la` เจอครบทุกที่:

1. `index.html` → เพิ่ม 3 บรรทัดใน `<head>` คืน (`canonical`, `og:url`, `og:image` แบบ URL เต็ม)
2. `index.html` → JSON-LD: เพิ่ม `"url"` คืน และเปลี่ยน `logo`/`image` เป็น URL เต็ม
3. `sitemap.xml` → เอา 2 บล็อกออกจากคอมเมนต์ แล้วใส่โดเมนจริง
4. `robots.txt` → เปิดบรรทัด `Sitemap:`
5. Cloudflare Pages → **Custom domains** → Set up a domain

> ระหว่างที่ยังไม่มีโดเมน Google กับ Facebook จะใช้ URL จริงของหน้าที่โหลดมาแทนเอง
> แต่รูปตัวอย่างตอนแชร์ลิงก์ (og:image) อาจไม่ขึ้นในบางแอป เพราะเป็นเส้นทางแบบย่อ

> แนะนำซื้อที่ **Cloudflare Registrar** เพราะขายราคาทุน .com ประมาณ $10.44/ปี (~370 บาท) และจัดการที่เดียวจบ
